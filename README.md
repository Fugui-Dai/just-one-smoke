# 【我抽一支】无烟替瘾器 · 微信小程序
> 赛博拟真替烟与健康戒烟辅助工具 · 纯前端纯血零后端架构 · 倡导纯净健康新呼吸

---

## 📖 项目简介
**【我抽一支】** 是一款专为减烟、戒烟与替烟人群量身打造的沉浸式心理替瘾数字化工具。
结合微距拟真 3D 视觉建模、动态流体烟雾物理粒子引擎、白噪音与空间声学，提供全套真实的抽吸、吐烟、捏爆珠、弹烟灰与开盒仪式感，利用替代行为与认知自律辅助用户科学降低对尼古丁的依赖。

---

## ✨ 核心特色功能

1. **拟真 3D 抽吸机能**
   - **触控交互**：支持长按吸烟、松手呼气、轻触弹灰、手指捏爆珠。
   - **真实物理燃烧**：根据吸入时长动态渐进燃烧红热发光（Embers），烟灰层层堆叠并支持真实脱落重力飘散。
   - **空间氛围白噪音**：夜雨微风、静谧禅茶、炉火微光、海风微咸等多场景原声音效。

2. **名烟精品陈列展柜**
   - 收录 **29 款** 经典名烟与雪茄（软中华、南京炫赫门、黄鹤楼1916、万宝路冰蓝、高希霸等）。
   - 1:1 纯画幅精美名烟立面微缩陈列，支持 3D 深度翻盖开盒与整盒无损补满。

3. **赛博烟雾物理粒子引擎**
   - 内置 **12 种** 物理烟雾特效：经典烟圈、袅袅青烟、舒缓白雾、紫气东来、黑金流沙、极光星云、双爱心圈、金龙吐息、漫天繁星、盛世华彩、福愿金墨、赤焰神凰。
   - 默认搭载殿堂级 **步步高升**（吉语螺旋星河与流光缎带）。

4. **自律数据看板与数字孪生体**
   - **机能透视 · 数字孪生**：3D 全息医学扫描人体器官（双肺、心脏、神经、血管）动态展现自愈进度。
   - **自律存钱罐**：精准测算替烟省下的烟资与避免吸入的焦油克数。
   - **全国戒烟英雄榜**：全国替烟支数、省钱排行与点赞互动。

## 🛠️ 技术架构

- **宿主环境**：微信小程序 (WeChat Mini Program)
- **渲染引擎**：原生 Canvas 2D 高保真硬件加速渲染
- **动效体系**：自研物理粒子引擎 (`particleSystem.js`) + GPU 仿生血流动力学
- **本地持久化**：全本地高可靠闭环存储 (`storageService.js`)，无任何外部云端数据库依赖，保护用户隐私

## 🚀 快速启动与调试

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 打开微信开发者工具，选择 **导入项目**。
3. **项目目录**：选择本项目所在根目录 `just-one-smoke`。
4. **AppID**：填写您自己的小程序 AppID（或选择测试号）。
5. 点击导入即可进行预览与真机调试。
